# Bundled profile page fonts

These are unmodified copies of the existing mobile assets, served from the
PostDee origin. Ship this directory and its license notices with the API.

| Family | Source assets | License notice |
| --- | --- | --- |
| Prompt | `apps/mobile/assets/fonts/prompt/Prompt-Regular.ttf`, `Prompt-SemiBold.ttf` | `prompt-OFL.txt` |
| Anuphan | `apps/mobile/assets/fonts/anuphan/Anuphan-Regular.ttf`, `Anuphan-SemiBold.ttf` | `anuphan-OFL.txt` |

Anuphan's notice is preserved from
[Google Fonts](https://github.com/google/fonts/blob/main/ofl/anuphan/OFL.txt).
Prompt's notice is copied from the existing mobile asset directory.
Only the four explicit font filenames are public routes; this is not an arbitrary
filesystem or custom-font upload endpoint.
