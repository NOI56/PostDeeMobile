## 1. ขอบเขตของนโยบาย

นโยบายนี้อธิบายการประมวลผลข้อมูลเมื่อคุณใช้แอป PostDee และ API ของ PostDee เพื่อเลือกวิดีโอ บันทึกฉบับร่างในเครื่อง สร้างหรือแก้ไขข้อความด้วย AI เชื่อมบัญชีโซเชียล โพสต์หรือตั้งเวลา ดูผลการโพสต์ รับการแจ้งเตือนและประกาศสถานะบริการ ติดต่อทีมงานผ่านแชตในแอป จัดการแพ็กเกจและลิงก์ร้าน และลบบัญชี

PostDee พึ่งพาผู้ให้บริการภายนอกหลายรายตามหัวข้อ 6 ผู้ให้บริการเหล่านั้นอาจเป็นผู้ควบคุมหรือผู้ประมวลผลข้อมูลแยกต่างหากตามบริการของตน

## 2. ข้อมูลที่ระบบประมวลผล

| ประเภทข้อมูล | ตัวอย่างที่พบในระบบปัจจุบัน |
| --- | --- |
| บัญชีและการยืนยันตัวตน | Firebase UID, อีเมล, ชื่อที่แสดง, URL รูปโปรไฟล์, สถานะยืนยันอีเมล และสถานะยืนยันหมายเลขโทรศัพท์ หมายเลขโทรศัพท์และการส่ง OTP จัดการผ่าน Firebase Authentication |
| วิดีโอและเนื้อหา | ไฟล์วิดีโอ เสียงหรือเฟรมที่คัดจากวิดีโอ ชื่อไฟล์ ประเภทไฟล์ ขนาดไฟล์ แคปชั่น แฮชแท็ก เทมเพลต ข้อความประกอบ หน้าปก และการตั้งค่าลายน้ำ |
| ข้อมูลการโพสต์ | แพลตฟอร์มและรูปแบบการส่งที่เลือก (เช่น live/private/unlisted/draft, ข้อมูลกำกับ YouTube และแชร์ไปฟีด) วันเวลา สถานะคิว รหัสโพสต์จากผู้ให้บริการ ผลสำเร็จ/ล้มเหลว และข้อความผิดพลาด |
| การเชื่อมต่อโซเชียล | ชื่อแพลตฟอร์ม รหัส integration ของ PostPeer ชื่อบัญชีที่แสดง รหัสบัญชีภายนอก และ PostPeer profile ID ระบบปัจจุบันไม่เก็บรหัสผ่านของบัญชีโซเชียลในฐานข้อมูล PostDee |
| แพ็กเกจและการซื้อ | แพ็กเกจ สถานะสมาชิก วันสิ้นสุดรอบ รหัสลูกค้าหรือรหัสสมาชิก และเหตุการณ์วงจรสมาชิกที่ RevenueCat, App Store หรือ Google Play ส่งให้ระบบ PostDee ไม่ได้รับข้อมูลบัตรชำระเงินโดยตรงจาก flow ปัจจุบัน |
| โควตาและบันทึกการส่ง | จำนวนหน่วยโพสต์และเครดิตแคปชั่น AI ที่ใช้ บันทึกสถานะและผลการส่งแต่ละแพลตฟอร์ม รวมถึงประวัติการใช้นาทีตัดต่อ AI ของฟีเจอร์เดิมที่ยกเลิกแล้ว (ถ้ามี) ซึ่งเก็บไว้จนกว่าจะลบบัญชี |
| ข้อความติดต่อทีมงาน | ข้อความที่คุณส่งในแชตช่วยเหลือในแอป ข้อความตอบกลับจากทีมงาน เวลาส่ง และสถานะการสนทนา (เช่น รอทีมงานตอบหรือปิดแล้ว) |
| การแจ้งเตือนและอุปกรณ์ | Firebase Cloud Messaging token และชนิดแพลตฟอร์มของอุปกรณ์ เมื่อผู้ใช้อนุญาตการแจ้งเตือนและระบบ Firebase Messaging ทำงาน |
| ข้อมูลการใช้งานและข้อผิดพลาด | หมวดเหตุการณ์ เช่น เริ่ม/สำเร็จ/ล้มเหลวในการเข้าสู่ระบบ การเลือกวิดีโอ และผลการโพสต์ รวมถึง exception และ stack trace ผ่าน Firebase Analytics และ Firebase Crashlytics เมื่อ Firebase เปิดใช้งาน โค้ด event ที่กำหนดเองไม่ส่งเนื้อหาวิดีโอ แคปชั่น หรืออีเมลเป็น parameter และเมื่อเปิดใช้ Sentry แอปและ API จะส่งเฉพาะรายงานข้อผิดพลาดทางเทคนิคที่ผ่านการคัดกรอง โดยปิดการส่งข้อมูลระบุตัวตน ภาพหน้าจอ และประวัติการใช้งานหน้าจอ |
| ข้อมูลทางเทคนิคและความปลอดภัย | IP address ที่ API ใช้เป็นกุญแจจำกัดอัตราคำขอ และข้อมูลคำขอที่จำเป็นต่อการตรวจสอบ token การป้องกันการใช้งานเกิน และการแก้ปัญหา |
| ข้อมูลที่เก็บเฉพาะในอุปกรณ์ | ธีม สถานะผ่าน onboarding แบบร่างโปรไฟล์ แบบร่าง Link in Bio และค่าร่างบางเครื่องมือผ่าน SharedPreferences; ฉบับร่างโพสต์คัดลอกวิดีโอ หน้าปก/รูปต้นทาง (ถ้ามี) ชื่อไฟล์ แคปชั่น คำแนะนำ AI ลายน้ำ แพลตฟอร์ม และเวลาที่เลือกไว้ไปยัง Application Support ของแอป โดยแยกพื้นที่ด้วยรหัสบัญชีที่คงที่ (Firebase UID เมื่อใช้ระบบยืนยันตัวตนจริง) |

วิดีโอหรือเสียงที่คุณเลือกอาจมีใบหน้า เสียง ข้อมูลสินค้า หรือข้อมูลของบุคคลอื่น คุณต้องมีสิทธิและฐานที่เหมาะสมก่อนอัปโหลดหรือเผยแพร่ข้อมูลเหล่านั้น

## 3. แหล่งที่มาของข้อมูล

เราได้รับข้อมูลจาก:

1. คุณ เมื่อเข้าสู่ระบบ กรอกข้อมูล เลือกวิดีโอ สร้างโพสต์ ตั้งเวลา หรือเลือกการตั้งค่า
2. Firebase Authentication เมื่อยืนยันตัวตน อีเมล หรือหมายเลขโทรศัพท์
3. PostPeer และแพลตฟอร์มโซเชียลที่คุณเลือกเชื่อมต่อ
4. RevenueCat, Apple App Store และ Google Play สำหรับสถานะการซื้อและสมาชิก
5. SDK และระบบของ PostDee สำหรับเหตุการณ์การใช้งาน ข้อผิดพลาด โควตา และความปลอดภัย

## 4. วัตถุประสงค์ในการใช้ข้อมูล

เราใช้ข้อมูลเพื่อ:

- สร้างและรักษา session ของบัญชี ตรวจสอบสิทธิแพ็กเกจ และป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต
- บันทึกและเปิดฉบับร่างโพสต์ต่อบนอุปกรณ์เดิมโดยไม่เริ่มขั้นตอนเผยแพร่
- อัปโหลด ประมวลผล พรีวิว และส่งวิดีโอไปยังแพลตฟอร์มที่ผู้ใช้เลือก
- จัดคิว ตั้งเวลา ติดตามผล และแจ้งผลการโพสต์
- สร้างแคปชั่นจากคลิปที่คุณเลือกด้วย AI
- แสดงเทมเพลต ปฏิทิน โควตา และสถานะการส่ง
- ตอบคำถามและช่วยเหลือผ่านแชตในแอป และแจ้งประกาศสถานะบริการ
- จัดการการซื้อ การกู้คืนสิทธิ และเหตุการณ์ต่ออายุ/ยกเลิกแพ็กเกจ
- วิเคราะห์ความเสถียรของแอป ตรวจจับข้อผิดพลาด จำกัดอัตราคำขอ และรักษาความปลอดภัย
- ดำเนินการตามคำขอลบบัญชีและข้อกำหนดที่ใช้บังคับ

## 5. การประมวลผลด้วย AI

เมื่อคุณเลือกใช้ฟีเจอร์ AI ระบบอาจส่งสื่อที่เกี่ยวข้องไปยังผู้ให้บริการที่ตั้งค่าไว้ดังนี้:

- **Google Gemini**: ใช้เสียงจากคลิป และสำหรับแพ็กเกจ Pro อาจใช้เฟรมที่คัดจากคลิปด้วย เพื่อช่วยสร้างแคปชั่น SEO แฮชแท็ก และ hook
- **ElevenLabs**: ใช้เสียงจากคลิปเพื่อถอดเสียงด้วย Scribe v2 เป็นทางสำรองในการสร้างแคปชั่นเมื่อระบบไม่ได้ตั้งค่าแคปชั่นจาก Gemini
- **OpenAI**: เฉพาะเมื่อทีมงานเปิดผู้ช่วยตอบแชตอัตโนมัติ (Dot) ข้อความที่คุณส่งในแชตช่วยเหลืออาจถูกส่งไปเพื่อร่างคำตอบ ค่าเริ่มต้นของระบบปิดผู้ช่วยนี้ไว้

ผลลัพธ์ AI อาจไม่ถูกต้อง ไม่ครบถ้วน หรือไม่เหมาะกับบริบท ผู้ใช้ควรตรวจสอบก่อนนำไปใช้หรือเผยแพร่ทุกครั้ง

## 6. ผู้ให้บริการและผู้รับข้อมูล

ระบบปัจจุบันอาจส่งข้อมูลเท่าที่จำเป็นให้ผู้ให้บริการต่อไปนี้:

| ผู้ให้บริการ | หน้าที่ใน PostDee | ข้อมูลที่เกี่ยวข้อง |
| --- | --- | --- |
| Google Firebase | Authentication, Analytics, Crashlytics และ Cloud Messaging | บัญชี/การยืนยันตัวตน เหตุการณ์การใช้งาน ข้อมูลข้อผิดพลาด และ device token |
| Render และ PostgreSQL บน Render | โฮสต์ API และฐานข้อมูล production ใน region Singapore ตาม `render.yaml` | บัญชี โพสต์ เทมเพลต สมาชิก โควตา device token และรหัสการเชื่อมต่อ |
| Cloudflare R2 | เก็บวิดีโออัปโหลดชั่วคราวและให้ signed URL | ไฟล์วิดีโอและ metadata การอัปโหลด |
| Google Gemini | สร้างแคปชั่นจากคลิป | เสียงจากคลิป เฟรมที่คัด (Pro) และคำสั่งที่เกี่ยวข้อง |
| ElevenLabs | ถอดเสียงเป็นทางสำรองสำหรับแคปชั่น AI | เสียงชั่วคราวจากคลิปและคำศัพท์เฉพาะที่ตั้งค่าไว้ |
| OpenAI (เฉพาะเมื่อเปิดผู้ช่วย Dot) | ร่างคำตอบแชตช่วยเหลือ | ข้อความในแชตช่วยเหลือ |
| Sentry (เมื่อเปิดใช้) | รายงานข้อผิดพลาดของแอปและ API | รายงานข้อผิดพลาดทางเทคนิคที่ผ่านการคัดกรอง ไม่รวมข้อมูลระบุตัวตนหรือภาพหน้าจอ |
| PostPeer | เชื่อมบัญชีและส่งไปยังแพลตฟอร์มโซเชียล | รหัสบัญชี/integration แคปชั่น แพลตฟอร์ม รูปแบบ live/private/unlisted/draft เวลาโพสต์ และ signed URL ของวิดีโอ |
| TikTok, YouTube, Instagram และ Facebook หรือแพลตฟอร์มที่ผู้ใช้เลือก | รับโพสต์หรือร่างตามคำสั่ง | เนื้อหา วิดีโอ แคปชั่น การมองเห็น/ร่าง และข้อมูลกำกับที่ผู้ใช้ยืนยัน |
| RevenueCat, Apple App Store และ Google Play | ซื้อ กู้คืน และซิงก์สิทธิสมาชิก | รหัสผู้ใช้/สมาชิก ผลิตภัณฑ์ สถานะและเหตุการณ์การซื้อ |
| Apple ในฐานะผู้ให้บริการ backup ของ iOS (เมื่อผู้ใช้เปิดใช้) | สำรอง/กู้คืนข้อมูลแอปตามการตั้งค่าอุปกรณ์ | ฉบับร่าง วิดีโอ หน้าปก และข้อมูลประกอบใน Application Support อาจถูกรวมใน backup บน iOS ส่วนแอป Android ปิดการสำรองข้อมูลแอปและการย้ายข้อมูลไปเครื่องใหม่ไว้ |

การกด **บันทึกร่าง** ไม่ส่งฉบับร่างไปยัง API, Cloudflare R2, PostPeer,
แพลตฟอร์มโซเชียล หรือระบบโควตา/คิวโพสต์ ฉบับร่างจะเริ่มเข้าสู่ flow เหล่านั้น
เมื่อผู้ใช้เปิดร่าง ตรวจสอบ และกดยืนยันโพสต์เท่านั้น การโหลดรายการ connection
หรือข้อมูลบัญชีส่วนอื่นของหน้าจออาจยังใช้ API ตามปกติและแยกจากการบันทึกร่าง

คำสั่ง **ส่งเป็นร่างเข้า TikTok** หรือ **เก็บเป็นร่างบนเพจ Facebook** เป็นร่างที่
ผู้ให้บริการ ไม่ใช่การบันทึกร่างข้างต้น เมื่อยืนยันแล้วระบบจะอัปโหลด เข้าคิว ใช้โควตา
และส่งข้อมูลให้ PostPeer/แพลตฟอร์มตามคำสั่ง

## 8. ระยะเวลาการเก็บและการลบข้อมูล

- ข้อมูลบัญชี โพสต์ เทมเพลต การเชื่อมต่อ สมาชิก และโควตาถูกเก็บในฐานข้อมูลตราบเท่าที่บัญชียังใช้งานหรือเท่าที่จำเป็นต่อบริการ
- วิดีโออยู่ใน Cloudflare R2 เพื่อรองรับการอัปโหลด AI การโพสต์ทันทีหรือที่ตั้งเวลา และการดึงไฟล์โดย PostPeer การลบหลังโพสต์สำเร็จเป็น best-effort และขึ้นกับการตั้งค่า production
- signed upload URL ปัจจุบันมีอายุประมาณ 5 นาที และ managed multipart session มีอายุประมาณ 1 ชั่วโมง ระยะเวลาดังกล่าวเป็นอายุ URL/session ไม่ใช่คำรับรองว่าไฟล์วิดีโอถูกลบภายในเวลานั้น
- Firebase Analytics, Crashlytics, Firebase Authentication, RevenueCat และผู้ให้บริการภายนอกเก็บข้อมูลตามการตั้งค่าบัญชีและข้อกำหนดของตน
- แบบร่างและค่าตั้งที่อยู่ใน SharedPreferences จะอยู่บนอุปกรณ์จนกว่าจะถูกเขียนทับ ล้างข้อมูลแอป หรือลบแอป
- ฉบับร่างโพสต์อยู่ใน Application Support แยกตามรหัสบัญชีที่คงที่ และไม่ซิงก์ผ่าน PostDee ไปยังอุปกรณ์อื่น แอปพยายามลบร่างที่เปิดอยู่หลัง API รับโพสต์เข้าคิวสำเร็จ แต่เก็บร่างไว้เมื่อขั้นตอนก่อนรับเข้าคิวล้มเหลว; หากการลบไฟล์หลังเข้าคิวล้มเหลว ร่างอาจยังอยู่และแอปจะแจ้งคำเตือน ผู้ใช้ลบร่างแต่ละรายการได้จากหน้าร่าง
- แอป Android ปิดการสำรองข้อมูลแอปและการย้ายข้อมูลไปเครื่องใหม่ (`allowBackup="false"` และ data extraction rules ที่ยกเว้นทุกพื้นที่) ส่วน iOS อาจรวม SharedPreferences และไฟล์ Application Support ใน device/iCloud backup ตามการตั้งค่าของผู้ใช้ ต้องตรวจ backup behavior ของ final binary ทั้งสองแพลตฟอร์มก่อนเผยแพร่
- ข้อความแชตช่วยเหลือเก็บในฐานข้อมูลตราบเท่าที่บัญชียังใช้งาน และถูกลบพร้อมบัญชี
- Flow ลบบัญชีปัจจุบันล้างข้อมูลฝั่งบริการและ session แต่ยังไม่ได้รับรองว่าจะล้างแบบร่างเฉพาะเครื่องทุกประเภทหรือสำเนาใน OS backup โดยอัตโนมัติ ผู้ใช้ควรลบร่าง ล้างข้อมูลแอป หรือลบแอปตามที่ระบบปฏิบัติการรองรับ
- หลังลบบัญชี ระบบเก็บรหัสบัญชีภายในและเวลาที่ยืนยันการลบเป็นหลักฐาน และเมื่อทีมงานลบตามคำขอทางอีเมล จะเก็บรหัสผู้ดำเนินการ เหตุผล และผลการลบด้วย บันทึกเหล่านี้ไม่มีอีเมล ชื่อ หรือเนื้อหาของผู้ใช้

การลบบัญชีฝั่งบริการถูกปิดใน Production ชั่วคราวจนกว่าจะผ่านการทดสอบลบบัญชีกับ
บริการจริงด้วยบัญชีทดสอบ; ระหว่างปิด API ต้อง fail closed ก่อน
เปลี่ยนข้อมูล เอกสารฉบับเผยแพร่ต้องระบุช่องทาง web/support สำหรับคำขอลบที่ใช้งานได้จริง
และสอดคล้องกับสถานะ release ในขณะนั้น

เมื่อผู้ใช้กด **ลบบัญชี** และการลบสำเร็จ ระบบจะยกเลิกงานที่อยู่ในคิว ตัดการเชื่อมต่อ PostPeer และลบโปรไฟล์ PostPeer ของผู้ใช้ ลบวิดีโอใต้ owner prefix ลบข้อมูลของผู้ใช้ในฐานข้อมูล และลบ Firebase identity เป็นลำดับสุดท้าย การลบบัญชี **ไม่ยกเลิกสมาชิกใน App Store หรือ Google Play** ผู้ใช้ต้องจัดการสมาชิกในร้านค้าก่อนหรือแยกต่างหาก

## 9. ความปลอดภัย

มาตรการที่มีในระบบรวมถึง Firebase ID token verification, การแยกข้อมูลตามผู้ใช้, signed URL อายุสั้น, server-side secret, owner-scoped media key, HTTP security headers และ rate limiting ขั้นตอนลบบัญชีมี durable marker สำหรับ managed upload และ durable owner barrier ในฐานข้อมูลที่รอให้งานของผู้ใช้ในทุก process เสร็จก่อนเริ่มลบ แต่ยังปิดใน Production จนกว่าจะผ่านการทดสอบกับบริการจริง

## 10. สิทธิและตัวเลือกของคุณ

- เลือกว่าจะให้แอปเข้าถึงคลังรูปภาพเพื่อเลือกวิดีโอหรือไม่
- เลือกว่าจะอนุญาตการแจ้งเตือนหรือไม่ โดยแอปขอ permission เมื่อผู้ใช้กดเปิดการแจ้งเตือน
- แก้ไขข้อมูลร่างโปรไฟล์ในแอป และตัดการเชื่อมต่อบัญชีโซเชียลที่รองรับ
- เริ่มคำขอลบบัญชีจากหน้าโปรไฟล์เมื่อฟีเจอร์ฝั่งบริการเปิดใช้งาน โดยอาจต้องเข้าสู่ระบบใหม่หาก session เก่าเกินกำหนด หรือขอลบโดยไม่ต้องใช้แอปผ่านหน้า `https://postdee-api.onrender.com/account-deletion` ซึ่งรับคำขอทาง `postdee.support@gmail.com` และแจ้งผลภายใน 30 วัน
- ลบฉบับร่างโพสต์แต่ละรายการจากหน้าร่าง และล้างข้อมูลเฉพาะเครื่องด้วยการล้างข้อมูลแอปหรือลบแอป; สำเนาใน OS backup ขึ้นกับการตั้งค่าและวิธีจัดการ backup ของอุปกรณ์

เมื่อ Firebase ถูกเปิดใช้งาน โค้ดปัจจุบันเปิด Firebase Analytics และ Crashlytics อัตโนมัติและยังไม่มีสวิตช์ opt-out แยกในแอป
